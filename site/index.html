Install Focused

Works straight out of the box. There's a Gemini API key already inside, so no accounts, no setup — just install and hit Organize. (It's shared with everyone trying it, so be gentle.) You can always swap in your own key in Settings, or run it free with local Ollama.
  1. Download focused-judges.zip and unzip it.
  2. Open chrome://extensions (click to copy) — Chrome, Brave, Edge, Arc all work.
  3. Turn on Developer mode (top-right toggle).
  4. Click Load unpacked and select the unzipped focused folder.
  5. Pin Focused from the puzzle-piece menu, open a messy window, and hit Organize tabs.

Prefer your own keys? Download the clean build (no key inside) and add one in Settings.
