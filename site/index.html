More than a sorter

Everything runs locally in the extension. Your tabs go to the AI provider you pick — nowhere else.

Groups by intent, not domain

Two YouTube tabs about different topics land in different groups. Names are specific — “O1 Visa”, not “Research”.

Work first, fun last

Groups are ranked by importance and ordered on the tab strip: deep work on the left, entertainment on the right.

Bring your own AI

OpenAI, Anthropic, Gemini, or a local Ollama model for completely free, completely private organizing.

Budget cap built in

Tracks estimated spend from real token usage and refuses to call the API past your limit. Default cap: $1.

Undo everything

Organize, dedupe, merge windows, ungroup — one undo restores groups, order, pins, even reopens closed duplicates.

Tab-count watchdog

Cross your threshold and Regroup badges the icon and offers to clean up. It nags so your coworkers don't have to.

Install Regroup

Judge build — API key included. This download ships with a Gemini API key baked in so you can try it with zero setup. The key is rate-limited and spend-capped, so please be kind to it. Regroup is open source and designed for you to bring your own key (OpenAI, Anthropic, Gemini) — or run it free and fully local with Ollama.
  1. Download regroup-judges.zip and unzip it.
  2. Open chrome://extensions in Chrome (or Brave / Edge / Arc).
  3. Turn on Developer mode (top-right toggle).
  4. Click Load unpacked and select the unzipped regroup folder.
  5. Pin Regroup from the puzzle-piece menu, open a messy window, and hit Organize tabs.

Prefer your own keys? Download the clean build (no key inside) or install from source, then add a key in the extension's Settings.
