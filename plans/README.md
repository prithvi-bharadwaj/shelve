## Findings considered and rejected

- `site/` does not bloat the extension artifact because Vite builds only popup
  and options entries. It is being removed for duplication, drift, and unsafe
  distribution—not bundle size.
- No current committed provider credential was found in reachable Git history
  or the historical committed ZIP inspected during the audit. The
  credential-baking workflow is still unsafe; a separately distributed judges
  ZIP must be treated as compromised.
- `pnpm audit --audit-level high` reported no known vulnerabilities, so no
  dependency-upgrade plan was justified.
- Current OpenAI, Anthropic, and Gemini model defaults matched their official
  provider documentation; changing them would be churn without evidence.
- The optional all-sites permission is user-granted and supports page snippets.
  It is not being removed in this cleanup.
- The static demo’s `innerHTML` uses hardcoded simulation data; user-entered
  command text is rendered with `textContent`. No evidenced XSS issue was found.
